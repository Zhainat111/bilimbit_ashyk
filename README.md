# BilimBit UBT

11-сынып оқушыларына арналған информатикадан ҰБТ-ға дайындық платформасы. Ол «ҰБТ Informatics Lab» авторлық бағдарламасының цифрлық бөлігі.

Автор: Құлымжанова Ж.Т., Aqbobek Lyceum, Ақтөбе қаласы, 2026 жыл.

## Мүмкіндіктері

- Лақап атпен тіркелу және кодпен кіру
- Интерактивті 3D оқу картасы, 7 станция
- 13 тақырып, көрнекілік және есте сақтау карточкалары
- 15 зертхана: Python, SQL, логика
- 6 бөлім тесті және ҰБТ форматындағы 20 нұсқа
- Жеке кабинет, жетістіктер, сертификат, мұғалім панелі

## Маңызды ескертулер

- Тапсырмалар авторлық, нақты ҰБТ сұрақтары емес.
- Сервер жоқ. Оқушы деректері оның браузерінде сақталады, бұл репозиторийге түспейді.
- Мұғалім панелі құпиясөзбен қорғалмаған.

Сайт бір `index.html` файлынан тұрады және GitHub Pages арқылы ашылады.
